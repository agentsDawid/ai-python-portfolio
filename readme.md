# AI & Python Portfolio

**Practical software. Applied AI. Useful automation.**

A personal portfolio showcasing selected projects in **Python, artificial intelligence, machine learning, data analysis, and engineering tools**.

I'm an automation engineer with over 15 years of experience in industrial projects, now expanding my skills in software development and AI. This portfolio documents practical applications, experiments, and what I learn along the way.

## Built with

- **Zensical** and Markdown for the website
- **Python** for project metadata processing and site automation
- **GitHub Pages** as a publishing option

Project pages are maintained in `docs/projects/`. Their YAML metadata (`title`, `description`, `date`, `featured`, and `categories`) is used to generate project cards, listings, and navigation automatically.

## Run locally

Install the dependencies from the repository root:

```bash
python -m pip install -r requirements.txt
python scripts/site.py serve
```

Build the static site with:

```bash
python scripts/site.py build --clean
```

The generated site is written to `site/`.
